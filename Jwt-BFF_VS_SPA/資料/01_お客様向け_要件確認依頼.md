# 【ご確認依頼】システム操作の記録（証跡）に関する要件について

宛先：発注元ご担当者様（可能であれば経理部門・内部監査部門・監査法人IT監査ご担当者にもご確認ください）
発信：アプリケーション開発チーム
目的：**認証方式の設計を確定するために、貴社側でしか決められない要件を1点、文書でご回答いただきたい**

---

## 1. ご確認いただきたいこと（結論から）

> **本システム（マスタデータ管理・会計トランザクション管理）に対する操作について、「どの個人が・いつ・何をしたか」を、システム側の記録として追跡できることは要件ですか？**
>
> 特に、**別ベンダー様のコアシステム経由**でデータが参照・更新される場合も含めて、個人単位の追跡が必要かをご確認ください。

このご回答により、認証の仕組みが以下のどちらになるかが決まります。

## 2. 選択肢は2つです（技術詳細は省き、違いだけご説明します）

### 方式A：システム同士の認証のみ

ベンダー様のアプリは「アプリとして」我々のAPIに接続します。**当社側の記録には「ベンダーアプリがアクセスした」としか残りません**。その操作をした個人（社内の方か、外部払い出しアカウントの方か、誰か）は、ベンダー様側の記録だけが知っている状態になります。

- 利点：ベンダー様の改修が最小で済み、導入が早い
- 懸念：個人単位の追跡は、**ベンダー様のログの正確さ・保存期間・改ざん耐性に全面的に依存**します。監査の際、説明責任の範囲がベンダー様側に広がります

### 方式B：利用者ごとの認証連携

社内・外部を問わず、利用者は**共通の認証基盤（IdP）**でログインし、どのアプリ経由の操作にも「誰の操作か」が記録されます。

- 利点：**個人単位の操作証跡が当社システムの記録として残ります**。副次効果として、社内の方は1回のログインで両システムを利用できます（シングルサインオン）。昨今の「認証基盤を統一したい」というお話とも合致します
- 影響：ベンダー様のアプリに認証連携の改修が必要です。また、外部利用者のアカウント発行・棚卸しの運用責任を関係者間で取り決める必要があります（後述）

### 比較の目安

| | 方式A | 方式B |
|---|---|---|
| 「誰が操作したか」が当社記録に残る | ✗ 残らない | ✓ 残る |
| 内部統制（J-SOX等）の監査対応 | ベンダー様ログとの突合が前提 | 当社ログで完結 |
| ベンダー様の追加開発 | ほぼ不要 | 必要（認証連携対応） |
| 外部利用者のアカウント管理 | ベンダー様任せ | 共通基盤で集中管理（棚卸し可能） |
| 退職・契約終了時のアクセス遮断 | ベンダー様の対応次第 | 共通基盤で即時遮断 |

## 3. 弊チームの見解

本システムは**会計データ**を扱うため、貴社が金融商品取引法の内部統制報告制度（J-SOX）の対象である場合、本システムは「財務報告に係るシステム」としてIT統制の評価範囲に入る可能性が高いと考えています。その場合、**「誰がアクセスできるか・したか」の統制と証跡**は監査で確認される標準的な項目であり、**方式Aでは満たせません**。

つきましては、見解の押し付けではなく、**貴社の監査対応方針として**以下をご確認ください。

## 4. 具体的なご確認項目（ご回答をお願いしたい事項）

- [ ] **Q1.** 本システムはJ-SOX（内部統制報告制度）の評価範囲に入りますか？（経理・内部監査部門またはは監査法人にご確認ください）
- [ ] **Q2.** ベンダー様アプリ経由の操作を含め、**個人単位の操作証跡**は要件ですか？（Q1がYesならほぼ必然的にYesになる想定です）
- [ ] **Q3.** 操作ログの**保存期間**の要件はありますか？（監査法人のご指定があれば教えてください）
- [ ] **Q4.** 「認証基盤を統一したい」というお話の**推進主体（オーナー）**はどちらの部門ですか？方式Bはその構想の実体そのものになるため、合流して進めたいと考えています
- [ ] **Q5.** 外部利用者のアカウント発行・削除・定期棚卸しの**運用責任者**はどちらになりますか？（貴社／ベンダー様／弊社いずれか）

## 5. ご回答期限と影響

- ご回答目安：**設計確定の律速になっています**。可能であれば〔※期日を記入〕までにお願いします
- なお、ご回答を待つ間も共通部分（API・画面側の認証基盤）の開発は先行して進めており、手戻りは発生しません
- **方式Bとなった場合、当初想定（方式A相当）からのスコープ変更となります**。ベンダー様の改修規模・弊社側の追加作業・運用分担を整理した変更提案を別途ご提出します
